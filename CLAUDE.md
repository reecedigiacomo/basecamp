# BaseCamp

This repo is BaseCamp: the practices, skills, and project template that other projects are built on.

- **Follow `practices.md`** in this repo, all of it. It's the source of the rules every BaseCamp project follows, including this one.
- **Public repo:** No personal details, machine-specific paths, or secrets in any file.
- **Examples stay project-neutral:** Use generic examples (a parser, a CLI, a web handler), never details from a specific project.
- **`skills/third-party/`** is vendored: copied verbatim under its own license. Don't edit it. Record any change in its `SOURCE.md`.
